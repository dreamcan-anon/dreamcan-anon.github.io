# DreamCan

Project website for **Dream What I Can: Sparse Visual Planning for Long-Horizon Robot Manipulation**.

Website: https://dreamcan-anon.github.io/

This repository contains the static HTML, CSS, JavaScript, images, and demonstration videos used by the website. No build step or external dependencies are required.

## Local preview

From this directory, run:

```bash
python -m http.server 8765
```

Open http://localhost:8765.

## Publishing

GitHub Pages publishes the root of the `main` branch. The `.nojekyll` file enables direct serving of the static files. Push website changes to `main` to update the site.
